# 🍽️ 한양대 ERICA 학교 앞 맛집 지도 (5조)

## 1. 프로젝트 소개
한양대학교 ERICA 캠퍼스 주변의 검증된 학교 앞 맛집들을 한눈에 확인하고, 카테고리별 대표 메뉴와 한 줄 소개, 네이버 지도 위치·가격 정보까지 쉽게 찾아볼 수 있도록 제작한 웹페이지입니다.

## 2. 주요 기능
- **메인 페이지 (`index.html`)**: 전체 등록 맛집 수(총 33곳) 및 6개 카테고리(일식, 멕시칸, 카페, 한식, 아시안, 양식)별 현황 안내
- **맛집 및 메뉴 살펴보기 (`memu.html`)**: 카테고리별 맛집 필터링, 대표 메뉴 태그, 조원 추천 한 줄 소개 및 주소 제공
- **네이버 지도 연동**: 각 가게 카드에서 '네이버 지도에서 메뉴·가격 보기' 클릭 시 해당 가게의 상세 지도 및 가격 페이지로 바로 이동
- **맛집 데이터 관리 (`data.js`)**: 학교 앞 맛집 33곳의 상호명, 카테고리, 대표 메뉴, 도로명 주소, 추천 코멘트 데이터 구축
- **반응형 카드 UI 디자인 (`style.css`)**: 직관적인 카드 레이아웃 및 카테고리 배지 스타일링 적용
