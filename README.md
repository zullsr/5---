# 🍽️ 한양대 ERICA 학교 앞 맛집 지도 (5조)

## 1. 프로젝트 소개
한양대학교 ERICA 캠퍼스 주변의 검증된 학교 앞 맛집들을 한눈에 확인하고 메뉴와 가격 정보를 쉽게 찾아볼 수 있도록 제작한 웹페이지입니다.

## 2. 주요 기능
- **메인 페이지 (`index.html`)**: 학교 앞 맛집 전체 소개 및 메인 화면 구성
- **메뉴 및 상세 보기 (`memu.html`)**: 각 식당의 대표 메뉴와 가격 정보 안내
- **맛집 데이터 관리 (`data.js`)**: 식당별 위치, 카테고리, 추천 메뉴 데이터 정리
- **페이지 스타일링 (`style.css`)**: 사용자 친화적인 화면 디자인 및 레이아웃 구성

## 5. 사용한 오픈소스
- **Leaflet.js**: 웹 페이지 내 인터랙티브 지도 구현 (https://leafletjs.com/)
- **OpenStreetMap**: 학교 주변 지도 타일 데이터 제공 (https://www.openstreetmap.org/)
- **GitHub Pages**: 웹 호스팅 및 정적 페이지 배포 (https://pages.github.com/)
